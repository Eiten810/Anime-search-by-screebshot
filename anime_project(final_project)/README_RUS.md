# Поиск аниме по скриншоту

Система поиска аниме по загруженному изображению с использованием подхода **Image Retrieval**.

---

# Описание проекта

Цель проекта — разработка системы, позволяющей определить аниме по загруженному пользователем скриншоту.

В отличие от классической классификации изображений, система не пытается сразу определить класс изображения. Вместо этого изображение преобразуется в эмбеддинг (вектор признаков), который сравнивается с эмбеддингами изображений из базы данных с помощью косинусного сходства.

В рамках проекта были реализованы и сравнены несколько способов извлечения эмбеддингов для определения наиболее эффективного подхода.

---

# Основные возможности

- формирование собственного датасета;
- автоматическое извлечение кадров из серий аниме;
- сравнение нескольких моделей извлечения эмбеддингов;
- поиск похожих изображений по косинусному сходству;
- количественная оценка качества Retrieval-системы;
- модульная архитектура проекта.

---

# Используемые модели

В проекте реализованы четыре различных подхода:

- Gemini Embedding 2 (Original)
- Gemini Embedding 2 (512×512)
- ResNet50 (Classification)
- ResNet50 (Triplet Loss)

# Датасет

Для проекта был сформирован собственный датасет на основе кадров, автоматически извлеченных из серий аниме.

Итоговый объем датасета:

- **23 аниме**
- **24 009 изображений**

Разделение данных:

- Train — 70%
- Validation — 15%
- Test — 15%

Для корректной оценки качества поиска база эмбеддингов формируется **только по обучающей выборке**, а изображения тестовой выборки используются исключительно в качестве поисковых запросов. Такой подход исключает утечку данных между обучением и тестированием.

Для сравнения моделей используются Retrieval-метрики:

- Recall@1
- Recall@5
- Recall@10
- Mean Reciprocal Rank (MRR)
- Mean Average Precision (mAP)

# Использование

Проект состоит из нескольких независимых ноутбуков, каждый из которых отвечает за отдельный этап построения Retrieval-системы.

Рекомендуемый порядок запуска:

1. **preprocessing.ipynb**
   - подготовка датасета;
   - разделение изображений на обучающую, валидационную и тестовую выборки.

2. **training_resnet50.ipynb**
   - обучение ResNet50 как классификатора;
   - сохранение лучшей модели в папку `models/`.

3. **training_resnet50_triplet.ipynb**
   - обучение модели ResNet50 с использованием Triplet Loss;
   - сохранение лучшей модели в папку `models/`.

4. **Gemini_Original_embeddings.ipynb**
   - генерация эмбеддингов изображений в исходном разрешении.

5. **Gemini_512_embeddings.ipynb**
   - генерация эмбеддингов изображений размером 512×512.

6. **ResNET50_embeddings.ipynb**
   - генерация эмбеддингов обучающей выборки с использованием обученного классификатора ResNet50.

7. **ResNET50_triplet_embeddings.ipynb**
   - генерация эмбеддингов обучающей выборки с использованием модели Triplet Loss.

8. **evaluation.ipynb**
   - вычисление Retrieval-метрик;
   - сохранение результатов в папку `results/`.

9. **similarity_search.ipynb**
   - загрузка пользовательского изображения;
   - построение эмбеддинга;
   - поиск наиболее похожих изображений;
   - отображение Top-5 результатов.
